# Compilador para a Linguagem Zig

## Projeto — Linguagens Formais e Tradutores

Este projeto foi desenvolvido como parte das atividades da disciplina de **Linguagens Formais e Tradutores**.

O objetivo do projeto é desenvolver um compilador para uma linguagem baseada na sintaxe da **Zig**, trabalhando conceitos relacionados à análise e tradução de linguagens de programação.

O projeto contempla as principais etapas necessárias para transformar um código-fonte em uma representação de baixo nível, servindo como aplicação prática dos conceitos estudados na disciplina.
